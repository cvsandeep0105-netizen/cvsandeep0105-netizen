## Flagship Project

### Enterprise AI-Powered Real-Time EV Fleet Data Platform

A production-oriented end-to-end EV telemetry platform built around real vehicle data.

**Engineering highlights**

- 98M+ real telemetry records processed
- 7 real production EVs from the TUMFTM electric-vehicle-uds dataset
- 160,774 one-minute feature windows
- 8,251 quality-gated AI samples
- Real-time streaming architecture using Apache Kafka
- Distributed processing using Apache Spark / PySpark
- PostgreSQL operational and analytical storage
- FastAPI production API layer
- React product and demonstration layer
- Docker and Kubernetes deployment
- Data-quality gates with rejected-record handling
- ML anomaly detection using Isolation Forest
- Real-world model evaluation: F1 0.8619 | Recall 1.0000
- API benchmark: 20/20 successful requests
- API benchmark p95: approximately 77 ms
- Automated CI/CD and dependency security validation
- Container and Kubernetes validation
- Production-oriented testing and observability controls
